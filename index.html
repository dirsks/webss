How to Load the Library

Before loading the Kryzium admin panel, make sure the Roblox Studio environment is fully loaded. Call the module using the native require() function.

if not game:IsLoaded() then
    game.Loaded:Wait()
end

local Kryzium = loadstring(Game:HttpGet'https://kryzium.vercel.app/raw/script')();

Initial Customization (Optional)

The Kryzium:init() method lets you define the visual palette and gradients of the menu before rendering it on the player's screen.

Kryzium:init({
    Gradient = false,
    GradientColor = ColorSequence.new{
        ColorSequenceKeypoint.new(0, Color3.fromRGB(255, 0, 0)), -- Red
        ColorSequenceKeypoint.new(1, Color3.fromRGB(0, 0, 255))  -- Blue
    },
    GradientRotation = 0,
    CustomFont = false,
    Font = Enum.Font.SourceSansBold,
    CustomBGColor = false,
    BackgroundColor = Color3.fromRGB(40, 40, 40),
    CustomIntro = true,
    IntroColor = Color3.fromRGB(0, 0, 0),
    IntroTransparency = 0.4
})

Creating the Main Window

The MakeWindow function generates the base structure. This is where you set author information, Discord invites, and enable the internal notification system.

local window = Kryzium:MakeWindow({
    Image = 'Default', -- Insert your custom icon Asset ID here
    Name = 'Kryzium UI',
    DiscordLink = 'https://discord.gg/aA123',
    Author = 'dircs',
    Discord = false,      -- Enables Discord pop-up
    Notifications = true -- Activates the global alert system
})

Creating Tabs

Tabs divide your script into categories (e.g. Automation, Combat, Teleports). You can assign numeric icons or keep the default value.

local tab = window:MakeTab({Title = 'Main', Image = 'Default'})
local tab2 = window:MakeTab({Title = 'Farming', Image = 16898613509})

Buttons

Perfect for executing instant actions through a callback function.

tab:MakeButton({
    Title = 'Version',
    Callback = function() 
        print(game.PlaceId)
    end
})

Toggles

Used to enable or disable continuous functions (loops). The Value parameter returns a boolean (true or false).

tab2:MakeToggle({
    Title = 'Auto Farm',
    Toggle = false, -- Default initial state
    Callback = function(Value)
        print('Current state:', Value)
    end
})

Sliders

Ideal for setups that require range accuracy, such as walk speed (WalkSpeed) or jump power.

tab:MakeSlider({
    Title = 'Slider',
    Value = 0,
    MinValue = 0,
    MaxValue = 100,
    Callback = function(Value)
        print(Value)
    end
})

Keybindings

Binds a physical key to trigger the programmed function whenever it is pressed in-game.

tab:MakeKeybind({
    Title = 'Keybind',
    Keybind = Enum.KeyCode.F,
    Callback = function(Value)
        print('Key Pressed:', Value)
    end
})

Color Picker

Provides a graphical color palette interface for the user to change the tones of tracers or ESP boxes.

tab:MakeColourPicker({
    Title = 'Color Picker',
    Default = Color3.fromRGB(85, 0, 0),
    Transparency = 0,
    Flag = 'ESPColor',
    Callback = function(Color)
        -- Returns the selected Color3 object
    end
})

Warnings

Creates a textual or informational notice pinned at the top or body of the interface tab.

tab:MakeWarning({
    Title = 'A warning!',
    Container = 'Like!'
})
